# 验收清单

## 环境与安全

- [ ] Blender 版本为 5.1.2；项目、缓存、输出均在 S 盘。
- [ ] 源视频只读且有 SHA-256；默认不联网、不上传、不调用真实模型。
- [ ] 上传前展示文件、域名并要求确认。

## 白模功能

- [ ] 中文路径视频可导入、播放和逐帧定位。
- [ ] 镜头可切分/合并；相机跟踪有误差，失败可手工降级。
- [ ] 单人/多人代理和动作可编辑；白材质、灯光、阴影和参考开关正常。
- [ ] MP4 或 PNG 导出成功并记录哈希。

## 数据与恢复

- [ ] 算法结果与人工修正分开；中断可恢复；单镜头失败不破坏其他镜头。
- [ ] manifest 可回链到源视频、版本和输出。

## Seedance 适配器

- [ ] 离线请求 JSON 通过 schema 校验。
- [ ] 默认 `base_url` 为 `https://api.eggfans.com`，可通过环境变量覆盖。
- [ ] `GET /pricing` 模型/计价发现可解析并缓存，模型能力不会硬编码。
- [ ] API key 只来自环境变量或安全存储，不写入工程、manifest、日志或请求包。
- [ ] 文本、`video_url`、`audio_url` 在同一 `content` 数组，role 为 `reference_video`/`reference_audio`。
- [ ] 无音频时不伪造音频对象；模拟提交、轮询、失败、取消、重试通过。
- [ ] 真实调用仅在确认后执行并保留审计记录；提交/轮询路径与 Eggfans 实际契约一致。

## Agent 控制层

- [ ] 悬浮面板可拖动、可回车对话，主窗口不卡顿。
- [ ] 离线模式可识别状态、生成白模、运行 Blender、生成请求包、保存和打开输出目录。
- [ ] Agent 只能调用白名单工具，不具备编码、任意命令、媒体上传和远程提交权限。
- [ ] Agent 动作结果和失败信息写入项目历史与 `logs/pipeline.jsonl`。

## 质量门槛

- [ ] 30 秒固定样片达到 PRD 指标。
- [ ] 画面、文件、日志证据齐全；发布包可在干净工作区复现。
