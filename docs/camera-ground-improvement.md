# 相机和地面改进 - 2026-10-15

## 修改总结

已完成 **方案 A：相机透视化 + 地面平面**，直接针对"效果不得行"的核心问题。

## 关键改动

### 1. 相机改为透视投影 ⭐⭐⭐⭐⭐

**之前**：
- 正交相机 (`ORTHO`)
- 无透视感，所有物体等大
- 相机距离 Y = -30

**现在**：
- 透视相机 (`PERSP`)
- 焦距 ~28mm (垂直 FOV 65°，匹配手机相机)
- 相机距离 Y = -15 (更接近，增强透视感)
- 传感器高度 36mm (Blender 标准)

**效果**：
- ✅ 近大远小的真实透视
- ✅ 符合人眼观看习惯
- ✅ 更好匹配原片视角

### 2. 添加地面网格 ⭐⭐⭐⭐

**新增**：
- 20×20 网格平面
- 位置: Z = -1.6 (典型人物脚底高度)
- 尺寸: 20×20 世界单位
- 材质: 比背景稍暗的灰色 (0.15, 0.16, 0.18)

**效果**：
- ✅ 提供空间参考
- ✅ 人物有接触感，不再悬空
- ✅ 便于判断接地是否正确

### 3. 改进深度估算 ⭐⭐⭐

**之前**：
```python
depth = p[2] * view_width * 0.35
depth = max(-2, min(2, depth))  # 硬限制 ±2
```

**现在**：
```python
depth_scale = view_width * 0.5  # 更合理的缩放
depth = p[2] * depth_scale
depth = max(-8, min(8, depth))  # 扩大范围 4 倍
```

**效果**：
- ✅ 多人场景的前后层次更明显
- ✅ 适配透视相机的景深
- ✅ 减少人物重叠错误
