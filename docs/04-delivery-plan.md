# 分阶段交付计划

## 阶段 0：基线（1—2 天）

交付样片规格、硬件/软件检查、项目模板、S 盘目录和隐私规则。验收：不联网即可完成环境检查，源视频哈希可复现。

## 阶段 1：Blender 白模 MVP（3—5 天）

导入视频、镜头切分、参考视频层、手工相机、地面/墙/道具/人物占位体、白模渲染。交付 Blender 工程模板、插件骨架、30 秒样片 MP4 和说明。验收：中文路径可用，中断后不覆盖源文件。

## 阶段 2：相机与姿态（5—10 天）

加入相机跟踪、姿态 worker、多人 ID、骨骼重定向、脚底接地、置信度和修正层。交付关键点 schema、worker、导入器和误差面板。验收：固定样片达到 PRD 指标；失败镜头可降级。

## 阶段 3：资产与批处理（3—5 天）

角色/场景/道具资产库、镜头模板、批量导出、联系人表、可恢复队列。验收：至少 10 镜头批处理，单镜头失败不影响其他结果。

## 阶段 4：Eggfans API / Seedance 2.5 适配器（3—5 天）

以 `https://api.eggfans.com` 为默认 `base_url`，通过 `GET /api/pricing` 获取模型与计价，完成离线请求包、参考媒体上传、原生 content 构建、提交/轮询/下载、失败重试。交付 Eggfans adapter、模拟服务测试和真实调用手册。验收：默认离线；确认后才能上传；API key 不落盘；请求可回链到 shot/version；未知的提交/轮询路径在真实调用前完成契约确认。

## 阶段 5：试点发布（5—10 天）

使用 3—5 段已获授权样片做性能、稳定性和质量复盘，交付发布包、版本说明、已知问题、回滚包和培训文档。真实运行证据必须包含画面、输出文件、日志和请求记录。

## 里程碑与停止条件

M1 离线白模可用；M2 相机/姿态达标；M3 批处理稳定；M4 Seedance 模拟测试通过后再申请真实调用。出现数据丢失、未授权上传或源文件覆盖时立即停止并回滚。
