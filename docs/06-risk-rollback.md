# 风险与回滚

| 风险 | 预防 | 降级/回滚 |
|---|---|---|
| 单目深度不确定 | 置信度、手工尺度、低模定位 | 手工相机和占位体 |
| 遮挡/快速动作 | 平滑、IK、人工修正层 | 静态代理或关键帧 |
| 中文路径/编码 | UTF-8、哈希、中文样片 | 重新定位，不移动源文件 |
| 供应商契约变化 | adapter、schema、模拟服务 | 离线请求包/旧 adapter |
| 未授权上传 | 默认离线、确认框、审计 | 取消任务，清理临时 URL |
| 中断/磁盘不足 | checkpoint、原子写入 | 最近 checkpoint 恢复 |
| 模型/驱动不兼容 | 环境检查、隔离环境 | 手工模式或 CPU 模式 |

每次交付生成时间戳发布目录和 manifest；升级前备份工程、配置和 adapter。回滚只切换版本目录，不删除源视频、历史导出和审计日志。
