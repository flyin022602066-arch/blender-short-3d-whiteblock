# 白模仓库与人物几何优化

当前默认 `human_v3` 使用连续人体网格、164 根骨架、蒙皮与细分表面，用 EEVEE 渲染。逐帧烘焙及两轮变形网格复核减少穿模；仓库标注“真人 · 待复核”，可连接 Blender / MCP，由 Agent 调整手脚、镜头、人体轮廓并另存重渲染。修订镜头重新检查自身质量，剩余相交会显示警告。详细操作见 [Blender CLI / MCP 使用](10-human-whiteblock-blender-integration.md)。下文 `mannequin_v2` 记录保留的旧代理模式。

桌面左侧新增“白模仓库”。完成一键转换后自动归档并选中新预览，既支持完整视频，也支持单镜头。仓库按原片和批次显示缩略图、生成时间、时长、分辨率和版本；支持搜索、软件内播放/暂停/拖动进度、外部播放、打开输出目录、继续编辑项目及打开 Blender 工程。Agent 可用“查看白模仓库”“打开白模仓库”操控新入口。

进度条支持鼠标滚轮，每格跳转一秒；点击画面后，可用空格播放/暂停、左右键跳转。1020×680 最小窗口保留完整操作按钮。损坏的仓库索引会通过刷新重建，缩略图生成失败不会隐藏已生成的视频；打开 Blender 优先使用所选项目保存的路径，再尝试全局设置与本机探测。

历史视频通过扫描固定工作区的项目与导出目录找回。仓库索引和缩略图保存在 `output/library`，原视频仍在 `output/exports/<批次>`，不复制或覆盖旧视频。`.part` 文件、损坏视频和原片不作为白模入库；刷新时移除已经不存在的视频索引。旧版白模标记为早期版本，历史结果不会被自动重写。

`mannequin_v2` 改进了人物代理：在每个镜头内去除重复人物观察、抑制关键点抖动、限制躯干比例、将折臂移至胸前安全层、为人物分配独立近似深度层，并逐帧烘焙。Blender 模型包含平滑部件、肩桥、颈部、关节、手脚，绑定到命名骨架；每个人物合并为一个带骨架修改器的白模对象，便于后续移动整体、修改控制骨或替换几何。骨架是代理部件控制架，不等同于标准人体变形骨架或已完成的 IK 重定向。

默认预览最长边由 640 提高到 1280，保持原片比例，不把低分辨率输入强制放大。该原片输出 720×1280、24 fps、721 帧。场景规格保留原始关键点与优化后的逐帧动作、几何版本和质量计数。

旧代理模式的穿模检测覆盖保守手臂/躯干代理体和人物之间的深度区间。新版人体模式检查已变形网格的人体间表面交叉与前臂/躯干相交；不包含全部自碰撞、衣物、道具和纯体积包含。逐帧规则可降低穿胸、人物重叠、部件断开和动作插值问题，但深度分层不表示恢复了真实人物接触关系。新版无法确认的下肢保留正常骨架姿态；空景、局部特写、相机求解、背景、道具、遮挡和人体接触仍需人工复核。仓库保留这些说明，不能把近似白模标记为完整场景重建。

姿态分析、Blender 渲染、缩略图和软件内播放均在本地执行。新仓库不会主动调用 Eggfans 或上传用户素材。
