# 需求规格（PRD）

## 项目目标

以 Blender 5.1.2 为主控，把已有短剧视频反推为可编辑的 3D 白模动态分镜，并输出角色、场景、道具和镜头参考包，供 Seedance 2.5 等视频模型进行二次渲染。

## 范围

首版包含视频导入、镜头切分、参考视频对齐、摄像机跟踪、人体姿态与代理骨骼、低模场景和道具、白模渲染、Eggfans API 的 Seedance 请求/轮询适配器、离线请求包、日志和版本追溯。明确不包含单目视频完整背面恢复、真实材质自动重建、模型训练和未经确认的远程生成。

## 用户与用户故事

- 导演：导入视频并逐镜头检查白模走位、构图和节奏。
- 分镜师：修改相机、角色、道具后重新导出可执行镜头。
- AI 视频制作人员：导出带角色/场景/道具参考的请求包，保持连续性。
- 负责人：查看源视频、算法版本、人工修正、请求和结果的完整链路。

## P0 必须交付

1. 项目和素材管理：S 盘路径、中文路径、源文件只读、SHA-256。
2. 镜头与参考视频：自动/手工切分、逐帧定位、参考叠加。
3. 相机跟踪：跟踪点、求解误差、失败时手工相机降级。
4. 白模：地面、墙、道具、人物代理、白材质、基础灯光和阴影。
5. 动作：单人/多人关键点或骨骼动画，置信度、遮挡和人工修正。
6. 导出：MP4/PNG、参考帧、manifest 和哈希。
7. Seedance 适配：默认离线；确认后才经 Eggfans API 上传/提交；`base_url` 默认配置为 `https://api.eggfans.com`，模型发现/计价入口为 `/api/pricing`；保留同一 `content` 数组中的 `video_url`/`audio_url` 与 role。
8. 日志：project_id、shot_id、job_id、阶段、耗时、错误和输出路径。

## P1/P2

P1：批处理、资产库、脚底接地、联系人表、模拟服务和失败重试。P2：多视角重建、多人接触约束、布料/头发、口型和多供应商路由。

## 质量指标

30 秒固定样片白模流程成功率 ≥80%；可跟踪镜头相机求解达标率 ≥70%；单人无遮挡姿态有效帧 ≥85%；用户 15 分钟内完成一次导入—修正—导出。真实上传任务必须 100% 有确认记录。

## 非功能与待确认

支持 Windows 10/11 和 Blender 5.1.2；默认离线；中间产物可恢复；任务可取消；导出原子写入。待确认：样片规格、GPU/CUDA、授权网关、媒体上传策略、输出格式。
